# ダンス試作計画の仮の人物像による評価

- 実施日: 2026-10-15
- 状態: SOLサブエージェント3体の独立した評価を受け、計画へ反映済み。実ユーザーの確認は未実施
- 評価対象: [21の作り直し計画](./21_camera_free_dance_comparison_plan.md)の改訂前の内容
- 使用モデル: 3体とも`gpt-6.1-sol`。同じモデルで異なる人物設定を与えたもので、実在する3人の回答ではない
- 範囲と対象の正本: [03の1.2節と2章](./03_mvp_definition_and_roadmap.md)

## 1. 評価の方法

ユーザーの依頼により、3体へ別々の架空の人物像を渡し、同じ計画を読んでもらった。他の評価結果は渡さず、最初に試す理由、離れそうな場面、2案への期待と懸念、優先して直す点を整理した。ファイルの編集は親エージェントだけが行った。

曲と動く見本は未制作である。サブエージェントには、音を聴いた、踊れた、疲れたといった体験や、実際の子の発言を作らないよう指示した。人物像の好みや生活条件も、調査で得た事実ではなく、評価のために置いた仮定である。

この記録は確認すべき仮説を探すためのもの。好まれる案、需要、投稿したくなる割合、実際の使いやすさの証拠にはしない。3体で同じ懸念が出ても、同じモデルの推測が重なっただけの可能性がある。

年齢による好みの一般化や、性別による好みの割り当ては行っていない。実際の参加者を、この3つの設定どおりに集めることも決めていない。

## 3. 各評価の要点

### 3.1 友達と手振り動画を投稿する人物像

短い曲と動きが一緒に分かり、長い説明を読まずに試せることが、始める理由になりそうだという評価だった。A案は設定した好みに近いが、「かわいい」という名前だけでは選べない。B案も、目線や止め方を自分で変える余地はありそうだが、止める場所が初見で分かるかは不明である。

入口をすぐ再生できるようにすること、自由なポーズを見本でも示すこと、曲を知っていたかに加えて友達の踊りを見たことがあるかを聞くことが提案された。

### 3.2 ダンス経験がある人物像

座ったままでも、肩から肘、手首へ動きがつながり、音に合う部分があれば使う理由になりそうだという評価だった。A案は手を添えて指すだけ、B案は同じ速さで流して止めるだけだと、物足りない可能性がある。曲と動きがない状態では、B案の採用は判断できない。

普段の動画で足りる可能性、同じ振りを2回踊る理由、座位では物足りない可能性を確認項目へ入れる提案があった。立位へ広げる前に、座った短いお手本のまま試したいかを聞く案だった。

### 3.3 ひとりで覚えてから友達に見せる人物像

撮影なしで短い見本を繰り返せることは、設定した使い方に合いそうだという評価だった。初めての動きを見ただけで覚えられず30秒へ進む場合や、再挑戦のたびに選び直しや回答が必要な場合は、負担になる可能性がある。

同じ短い見本を任意に繰り返すこと、回答なしで同じ案を試し直せること、小さな音量と狭い机周りでの確認が提案された。曲の好み、覚えやすさ、友達とも踊りたいかは判断できないという留保もあった。

## 4. 計画へ反映したこと

以下は親エージェントが、評価内容を既存の範囲と照らして選んだ変更である。サブエージェントの意見を、多数決で仕様にしたわけではない。

| 指摘と担当 | 計画へ反映した最小の変更 | 実際に確かめること |
|---|---|---|
| 入口で説明や操作が多いと始めにくい可能性。手振り投稿の人物像 | 10〜15秒の音と動きの見本を1回の操作で再生。長い説明を読まずに30秒へ進める。案の名前より曲名と中身を見せる | 操作を教えずに、再生と開始へ進めるか |
| 初めての振りを覚える時間と、再挑戦の負担。友達限定投稿の人物像 | 同じ短い見本を任意に繰り返せる。終了後は同じ案へ1回で再挑戦でき、回答や案の選び直しを挟まない | 見本だけで次の動きが分かるか。感想を省略して再挑戦できるか |
| 自分で変えてよいと伝わらない可能性。手振り投稿の人物像 | 短い見本に別の終わり方を1つ示し、最後は好きなポーズと短く伝える | 自分のポーズへ変えてよいと理解するか |
| 慣れた人が練習したくなる部分と、繰り返す理由が弱い可能性。経験者の人物像 | 両案に、肩と腕のつながりや音に合わせた止め方が分かる箇所を用意。2回目に変えてみたい部分も聞く | 動きを増やさず、同じ振りをもう少しよく踊りたいと思うか |
| 低音が小音量で伝わらず、横の動きが机周りに収まらない可能性。友達限定投稿の人物像 | 小さな音量と狭い机周りを確認条件へ追加。低音以外の区切りの音も確認 | 音の区切りが聞こえるか。低い肘と小さな動きで続けられるか |
| 友達や普段の動画との関係、座位の制約。手振り投稿・経験者の人物像 | 曲や振りを見たことがあるか、普段の動画で十分か、座位のまま試したいかを必要に応じて聞く | 曲の好み、使う理由、今回の範囲への不満を同じ理由にまとめていないか |

短い見本、任意の感想、低い位置の動きは、改訂前にも計画にあった。今回は、それらの操作回数、繰り返し方、確認条件を明確にした。入口にカメラを使わないことも短く示す。質問の追加は、必須の長い入力フォームを増やす意味ではない。

## 5. 今回追加しないもの

3つの評価でも、カメラ判定、全身追跡、投稿、友達招待、難しい版、大量の選曲や衣装を今すぐ足す提案はしていない。短い見本の反復は、既存の見本を再生し直す範囲とし、速度変更や細かな区間指定は追加しない。

普段立って踊る人に今回の範囲が合わない場合は、その理由を残す。評価を通過させるために対象者を入れ替えたり、立位対応が決まったことにしたりしない。A案かB案のどちらかを、今回の仮の評価だけで採用することもない。

## 6. まだ判断できないこと

実物の曲の魅力、お手本の見やすさ、身体の動かしやすさ、疲れ、曲との合い方は未確認である。2案のどちらを踊りたいか、また開くか、友達と踊りたいかも、AIの評価では分からない。

次の成果物は21の計画どおり、実際に聴ける音源候補と、動きを見られる短いお手本である。今回行ったのは計画の評価と更新であり、アプリの作り直しや、実際の対象者への依頼は行っていない。

## 7. 改訂後の確認

3体それぞれに、改訂した21とこの記録を再び読んでもらった。提案の取り違え、必須の操作や回答の増加、立位対応や難しい版への範囲拡大、実ユーザーの反応に見える断定がないかを確認し、追加の修正指摘はなかった。

この再確認も、同じモデルによる文書の確認である。曲やお手本、実際の使いやすさの評価が済んだという意味ではない。今回は文書だけを更新し、アプリのコードは変更していない。
