# 文書を編集するときの決まり

`AGENTS.md` の「文書と言語」に加えて守ること。

- `docs/README.md` 冒頭の箇条書きは現在地の正本で、セッション開始時のhookが毎回そのまま文脈へ入れる。フェーズや実機結果が変わったら最初にここを更新する。
- 現在地の各項目は2〜3文に収める。書くのは結論、決まったこと、次にやること、詳細がある文書と章へのリンク。実測値の内訳、画面の細部、経緯は作業記録の文書に書き、ここへ複製しない。
- ゲート数値を変えたら `03`、`05`、`02` の対応表を同時に確認する。MVPスコープを変えたら `03` を先に更新する。
- 各文書の冒頭にある「更新日」「ステータス」を、内容を変えたときに合わせて更新する。日付は絶対日付（YYYY-MM-DD）で書く。
- 新しい作業計画や分析は次の番号で文書を作り、`docs/README.md` の「作業記録の一覧」へ足す。済んだ文書のステータスは「履歴」へ変える。
- 長い文書は全文を読まず、見出しを検索して必要な章だけ読む。
- 見出しに読点（、）を入れない。
