# 文書を編集するときの決まり

- 正本は `docs/README.md` の「文書の正本」表で決まる。仕様を変えるときは正本を先に直し、他文書はリンクで参照する。同じ仕様を複数文書へ複製しない。
- `docs/README.md` 冒頭の「更新日」「現在のステップ」「実装先行状況」「次の作業」「次の判断」は現在地の正本。フェーズや実機結果が変わったら最初にここを更新する。
- ゲート数値を変えたら `03`、`05`、`02` の対応表を同時に確認する。MVPスコープを変えたら `03` を先に更新する。
- 各文書の冒頭にある「更新日」「ステータス」を、内容を変えたときに合わせて更新する。日付は絶対日付（YYYY-MM-DD）で書く。
- 仮説、確定仕様、条件付き分岐、将来構想を同じ箇条書きへ混ぜない。
- 本文は日本語。コード識別子、API名、設定キー、コマンド、エラー文は英語原文のまま。
- 一次ソース（公式ドキュメント、標準仕様）で確認した事項には確認日と参照先を残す。資料にない結論は推論だと明示する。
- 見出しに読点（、）を入れない。
